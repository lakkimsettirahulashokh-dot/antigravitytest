Distributed Systems Question Prompt

How does the Raft protocol guarantee Log Matching and prevent conflicting committed entries?

rotate_right Tap to flip Active Recall Protocol
Verified Solution Answer & Key Mechanism

Raft satisfies the Log Matching Invariant: if two logs contain an entry with the same index and term, they store identical commands and are identical in all preceding entries.

Invariant: AppendEntries consistency check fails if previous log index & term don't match follower's log.
