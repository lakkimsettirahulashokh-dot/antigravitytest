01

Privacy Policy & DPDP Act Governance

TechPath operates under strict compliance with India's Digital Personal Data Protection (DPDP) Act, 2023, the Information Technology Act, 2000, and global data stewardship benchmarks. Consent given by students is free, specific, informed, unconditional, and unambiguous.

Categories of Personal Data Collected & Processing Purpose:
  • Account Identity: Display name, email address, password hash, and Google OAuth UID for authentication and profile segregation.
  • Academic Profile: Engineering branch/department, semester level, target skills, and target companies to filter relevant syllabi and learning modules.
  • Profile Media: User-provided avatar photos stored in isolated Supabase storage buckets; modifiable and removable at will.
  • Uploaded Materials: Lecture notes, syllabus outlines, and PDF documents parsed client-side or via ephemeral OCR buffers solely to generate notes or solve user doubts. Private files are never used to train public AI models.
  • AI Prompts & Generated Output: Text queries submitted to AI Doubt Solver and AI Copilot, proxied server-side to AI inference APIs without retaining student identity headers.
  • Mock Interview Media: Camera and microphone streams processed locally or via transient session memory; no persistent unencrypted surveillance or background retention.
  • Telemetry & Diagnostics: Browser user-agent strings, IP addresses for security rate-limiting, and error logs stripped of sensitive personal data.

Cross-Border Data Processing: TechPath utilizes enterprise cloud infrastructure (e.g., Supabase PostgreSQL in AWS/GCP regions and Google Gemini/OpenAI inference endpoints). Where data flows cross-border for processing, it is governed under standard contractual clauses and encryption standards safeguarding user privacy.

Withdrawal of Consent: Users maintain the statutory right to withdraw consent at any time. Withdrawal takes effect immediately upon processing, following which account data is purged within thirty (30) calendar days.

The PDF Analyzer and AI Notes tools allow students to extract study points from documents. The legal parameters governing uploaded materials include:

  • No Transfer of Ownership: Uploading notes or textbooks DOES NOT transfer intellectual property ownership to TechPath. TechPath acquires no proprietary rights over user documents.
  • User Responsibility: Users warrant that they hold valid ownership, license, or legal fair dealing exemptions for all submitted content.
  • Fair Dealing under Indian Law: Section 52(1)(a)(i) of the Indian Copyright Act, 1957 recognizes fair dealing for private study, non-commercial research, and personal education. TechPath tools are calibrated exclusively for private individual research.
  • Ephemeral Processing: Uploaded PDF files are parsed in temporary memory and are not published to public libraries or shared across student accounts.
  • Notice and Takedown: Copyright holders may submit takedown notices to lakkimsettirahulashokh@gmail.com. We acknowledge receipt within 24–48 hours and disable infringing content expeditiously.

Platform Security & Data Protection Architecture

TechPath implements multi-layered security controls to protect student records:

  • Row Level Security (RLS): PostgreSQL database tables enforce strict tenant isolation policies ensuring students can only access their own profile rows.
  • HTTPS & TLS 1.3: All web traffic is encrypted in transit using industry-standard Transport Layer Security.
  • Zero Client-Side API Keys: Third-party LLM credentials (Google Gemini, OpenAI) remain locked in backend environment variables and are never transmitted to student browsers.
  • File Validation & Rate Limiting: Uploaded files are restricted by MIME type and size (25MB cap). Endpoint rate-limiting mitigates brute-force attacks and abuse.
  • Responsible Vulnerability Disclosure: Security researchers discovering flaws are encouraged to report findings responsibly to lakkimsettirahulashokh@gmail.com without compromising user data.
